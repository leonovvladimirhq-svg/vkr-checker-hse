# ВКР-чекер

Веб-сервис автоматической проверки выпускных и курсовых работ для Школы коммуникаций НИУ ВШЭ.

Студент загружает работу (`.docx` / `.pdf`) и ссылку на базу данных исследования (папка Яндекс.Диска).
Сервис проверяет структуру, объём, базу данных и раздел об использовании ИИ по чек-листу своей
образовательной программы и выдаёт отчёт. Итоговое решение всегда принимает научный руководитель:
статус чекера служит подсказкой.

**Прод:** [вкр-чекер.рф](https://xn----ctbkawc3be3d.xn--p1ai), Yandex Cloud. Модель — Qwen 3.6 35B через Yandex AI Studio.

## Что умеет

| Модуль | Для кого | Что делает |
|---|---|---|
| **ВКР** (`/`, `/teacher`, `/report`) | ОП «Интегрированные коммуникации» (магистерский проект и диссертация), ОП «Реклама и связи с общественностью» (бакалаврская ВКР) | Чек-лист и статус: **Зачёт**, **Незачёт** или **Ожидает проверки**, если есть пункты, которые проверяет только человек. Объём в знаках считается программно, таблицы и иллюстрации исключаются. Для ОП РиСО формируется шаблон отзыва руководителя. |
| **Курсовые** (`/course`) | ОП «Интегрированные коммуникации» | Рекомендации вместо зачёта: сильные стороны, что доработать, разбор разделов, анализ базы данных. Для преподавателя — Word-отзыв по шаблону Программы практики. |
| **Панель преподавателя** (`/teacher`) | научные руководители, общий доступ ОП ИК | Каждый руководитель видит только работы своих студентов. Доступны чек-лист, файл работы, отзыв, выгрузка в Excel и PDF. |

Что сервис **не проверяет** (это всегда помечено как ручная проверка): длительность и качество
аудиозаписей, оригинальность текста («Антиплагиат»), содержание презентации, текст, вставленный картинкой.

## Быстрый старт

Нужны Node.js 20+ и npm 10+.

```bash
git clone https://github.com/leonovvladimirhq-svg/vkr-checker-hse.git
cd vkr-checker-hse
git checkout vkr-version-1     # рабочая ветка
npm ci
cp .env.example .env           # заполнить ключ и адрес модели, см. комментарии в файле
npm run dev                    # http://localhost:3000
```

База `data/vkr.db` создаётся при первом запросе. Как войти в панель преподавателя на свежей базе
и как поднять сервер с нуля, описано в [docs/RESTORE.md](docs/RESTORE.md).

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с hot-reload |
| `npm run build` | production-сборка (заодно проверяет типы) |
| `npm start` | запуск production-сборки |
