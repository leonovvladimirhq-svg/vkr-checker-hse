# Важные решения

Что решили, когда и почему. Перед тем как «упростить» что-то из списка ниже, прочитайте причину:
почти каждое решение принято после конкретного сбоя или по требованию заказчика.
Хронология изменений — в [CHANGELOG.md](CHANGELOG.md).

## Ограничения для будущих фич

- **Автовыставление оценок в LMS** (идея руководства, не реализована). ФИО и оценки — персональные данные, их обработка возможна только на инфраструктуре в РФ, без зарубежных ИИ-сервисов. Проверку работы (её делает модель) и внесение оценки (детерминированный код) нужно разделить. Предпочтительно использовать API или CSV-импорт LMS, а не браузерного агента. Финальное сохранение подтверждает человек, пароли преподавателей не хранятся, ведётся журнал действий.
