## 1. Объём работы (жёсткое требование к допуску)

Под объёмом КР понимается количество **знаков с пробелами** (с учётом ссылок), оформленных согласно требованиям:

| Язык работы | Минимальный объём | Последствие при недостаточном объёме |
|-------------|-------------------|--------------------------------------|
| Русский | **не менее 90 000 знаков с пробелами** | Студент **не допускается** к защите |
| Английский | **не менее 85 000 знаков с пробелами** | Студент **не допускается** к защите |

**В объём не входят:**
- Титульный лист
- Содержание
- Библиографический список (список использованных источников)
- Приложения (объём приложений не регламентирован)
- Все таблицы, диаграммы и прочие иллюстративные материалы (они выносятся в приложение)

## 2. Допуск к защите (критерии недопуска)

Студент **не допускается** до защиты КР в любом из следующих случаев:

1. **Несвоевременная загрузка** КР в специальный модуль ЭИОС НИУ ВШЭ.
2. **Некорректная загрузка** (неверный формат, файл не открывается).
3. Нарушения, предусмотренные Правилами внутреннего распорядка обучающихся НИУ ВШЭ.
4. **Несвоевременное предоставление баз данных** — отсутствие ссылки на БД на титульной странице или любые изменения в облачном хранилище после дедлайна загрузки.
5. **Несоответствие файлов в базе данных** требованиям по количеству и качеству (см. раздел 5 ниже).
6. **Объём КР меньше порога** (90 000 знаков с пробелами для русского, 85 000 для английского).
7. **Отсутствие любого обязательного структурного элемента:**
   - Для ИКР: введение, концептуальная глава, эмпирическая глава, заключение, список использованных источников, базы данных.
   - Для КП: введение, концептуальная глава (с обоими разделами — «Анализ научной литературы» и «Анализ рынка»), эмпирическая глава, заключение, список использованных источников, базы данных.
8. **Отсутствие указания на использование ИИ** при загрузке работы в ЭИОС и во введении к работе — при доказанном применении генеративной модели.
9. **Отсутствие раздела «Описание применения генеративной модели»** при применении ИИ.
10. **Некорректное использование ИИ** (см. раздел 4 ниже).

Студент, недопущенный к защите, получает неудовлетворительную оценку (0 баллов) и считается имеющим академическую задолженность.

## 3. Оригинальность (плагиат)

- **Оригинальность загруженной КР должна составлять не менее 80%** (доля корректного цитирования ≤ 20% от всего объёма работы).
- Проверка осуществляется системой «Антиплагиат» через ЭИОС (студент загружает работу самостоятельно).
- При оригинальности < 80% — отчёт направляется руководителю, который в течение 3 дней составляет служебную записку с заключением о (не)оригинальности.
- При обнаружении плагиата — дисциплинарное взыскание.

## 4. Правила использования искусственного интеллекта

> Это один из самых детально регламентированных разделов. Соблюдение критично — нарушение ведёт к недопуску.

### 4.1. Обязанности при использовании ИИ

При представлении итогового текста КР студент **обязательно** должен указать наличие/отсутствие в работе контента, сгенерированного алгоритмами автоматической генерации.

Если ИИ использовался, студент **обязан**:

1. **Указать во введении к работе** причины использования сервиса и разделы, в которых он был использован. Используется следующий шаблон:
   > «При подготовке данной работы автор использовал [НАЗВАНИЕ ИНСТРУМЕНТА/СЕРВИСА] в разделе(ах) [НАЗВАНИЕ РАЗДЕЛА(ОВ)] для [ПРИЧИНЫ]. После использования этого инструмента/услуги автор просмотрел и отредактировал контент, и взял на себя полную ответственность за содержание работы.»

2. **Добавить в текст работы специальный раздел «Описание применения генеративной модели»** после Заключения. В нём указать:
   - Цели применения генеративной модели.
   - Название модели, её версию, компанию-разработчика.
   - Адрес сайта в интернете (или иной источник модели).
   - Способ применения модели.
   - Оценку эффективности применения для решения поставленных задач.

3. **Корректно цитировать каждый запрос к ИИ:**
   - Исходный запрос к сервису.
   - Название сервиса, версия, компания-разработчик.
   - Дата обращения.
   - Сайт сервиса.
   - Пример формата: `"Describe the symbolism of the green light in The Great Gatsby" prompt. ChatGPT, 13 Feb. version, OpenAI, 8 Mar. 2023, chat.openai.com/chat`
   - **Полный текст, сгенерированный сервисом, в виде хорошо читаемого снимка экрана.**

4. При генерации изображений с помощью ИИ (например, для стимульных материалов):
   - Описать сервис и запрос в соответствующей части работы.
   - Вставить сгенерированный контент в приложение.

5. При использовании ИИ для целей эмпирического исследования:
   - Описать методологию применения сервиса.
   - Описать результаты в соответствующей главе.
   - Вставить сгенерированный контент в раздел «Описание применения генеративной модели».

### 4.2. Допустимо использовать ИИ для:

- **Улучшение читаемости** и языка (проверка отдельных частей черновика на грамматические и стилистические ошибки). НО: весь текст работы не может быть исправлен генеративным ИИ — детектор укажет, что текст не создан человеком.
- **Создание изображений для стимульных материалов** в разделе «Дизайн эмпирического исследования».
- **Короткие запросы**: сужение тематической области, формулировка проблем, мозговой штурм, доработка идей. **НО:** для аналитических запросов — обязательная проверка подтверждающих источников, информация требующая ссылки на авторитетный источник (тренды индустрии, доли рынка, результаты исследований) должна ссылаться напрямую. ИИ **не является авторитетным источником сам по себе**.

### 4.3. Допустимо БЕЗ информирования о использовании (если соблюдены условия):

- **Поиск источников** для последующего анализа. Каждый найденный источник должен быть проверен студентом на существование, анализ должен быть проведён самостоятельно. ИИ нельзя цитировать как авторитетный источник — цитата вставляется из текста оригинала.
- **Перевод текста** на иностранном языке (при соблюдении корректного цитирования).
- **Расшифровка аудио и видеозаписей** (при условии дальнейшей проверки текста студентом).

### 4.4. НЕДОПУСТИМО использование ИИ для:

- **Полного написания любой из частей работы** (концептуальной главы, обзора рынка, введения и заключения) — в том числе составления частей из кусков сгенерированного при помощи разных запросов без критического анализа и выстроенной авторской логики.
- **Создания текста, опирающегося только на ИИ как источник** информации, без указания первичных источников.
- **Переписывания чужого текста** с целью скрыть плагиат.
- **Переписывания при помощи одного сервиса текста, полученного при помощи другого сервиса.**
- **Генерации названий несуществующих источников.**
- **Составления выводов** из других частей текста / полученных в эмпирическом исследовании данных без критического анализа.

Даже при корректном цитировании ИИ объём контента, созданного с помощью генеративного ИИ, **не должен превышать объёмы допустимого цитирования** (20% от объёма работы).

При обнаружении нарушения любого из требований выше — студент **не допускается до защиты**.

## 5. Требования к базам данных (Приложение 19)

Базы данных — обязательный элемент КР. Ссылка на БД размещается на титульном листе.

### 5.1. Состав файлов по типам исследований

| Метод | Обязательные файлы |
|-------|---------------------|
| **Глубинные интервью / фокус-группы** | Гайд интервью; аудио/видео всех интервью/фокус-групп с разборчивой записью; транскрипты; материалы анализа транскриптов (таблица с кодировкой: наименования категорий и кодов, описание категорий, закодированные фрагменты). |
| **Качественный контент-анализ, дискурс-анализ, фрейм-анализ** | Исходные материалы для кодировки; таблица с кодировкой (категории, коды, фрагменты). |
| **Количественный контент-анализ** | **Кодировочный лист и кодировочная книга.** |
| **Опрос / опросный эксперимент** | Анкета; таблица с выгрузкой данных (с номерами наблюдений, значениями переменных, метаданными — дата, время заполнения и т.д.); материалы статистического анализа в специализированных программах (преподаватель должен иметь возможность проверить все шаги анализа). |
| **Этнографические исследования (включая нетнографию)** | Гайд интервью; видео/аудио интервью с информантами; транскрипты; материалы анализа (таблица кодировки); полевые записи за все сессии наблюдения; фото-видеоматериалы, скетчи, карты, цифровые следы (для нетнографии). |
| **Информационно-аналитический / лингвистический анализ текста; мониторинговые исследования** (BrandAnalytics, Youscan, Медиалогия, Public.ru, LexisNexis, IQBuzz) | Первичные или вторичные текстовые данные, собранные полевым или автоматизированным способом. |
| **Анализ визуальных материалов** | Исходные фото-видеоматериалы; таблица последовательности кадров/фотоматериалов, тайм-коды (для видео), параметры и результаты анализа каждого изображения/кадра. |
| **Кейс-стади** | В зависимости от дизайна: гайд интервью, анкета опроса, кодировочная таблица контент-анализа и др.; результаты сбора нескольких типов данных. |

### 5.2. Технические требования к файлам

- **Аудио**: MP3, WAV. Запись должна содержать идентифицирующие интервьюера признаки (имя, фамилия, учебная аффилиация). Голоса разборчивы.
- **Видео**: AVI, MOV, MPEG.
- **Транскрипты, дневник наблюдения**: WORD или PDF.
- **Таблица с выгрузкой количественных данных**: Excel.

### 5.3. Минимальная продолжительность аудио/видео

- **Глубинное интервью**: **не менее 45 минут**.
- **Фокус-группа**: **не менее 45 минут**.
- **Экспертное интервью**: **не менее 30 минут**.
- Максимальная граница определяется студентом самостоятельно на основании исследовательской необходимости.

### 5.4. Минимальное количество исследовательских сессий

| Стратегия | Минимум |
|-----------|---------|
| Качественная (интервью) | **≥ 10 глубинных интервью** |
| Качественная (фокус-группы) | **≥ 5 фокус-групп** |
| Экспертные интервью | **≥ 7 интервью** |
| **Смешанная / мультиметодическая** (количественные + качественные методы; два типа интервью — например, потребительское и экспертное) | **≥ 7 интервью, ≥ 3 фокус-группы** |

Количество должно быть **обосновано** в работе. Для качественных полевых исследований — отбираются единицы анализа с наибольшим количеством насыщенной информации.

### 5.5. Что должно быть в приложении самой работы (не только в БД)

- **Интервью/фокус-группа**: гайд + скринер + транскрипт одного показательного интервью/фокус-группы.
- **Этнография**: транскрипт показательного интервью + дневник/протокол наблюдения за одну сессию.
- **Количественный контент-анализ**: кодировочная книга.
- **Эксперимент**: материалы из экспериментальных и контрольной групп (изображения, формулировки, ссылки на видео).
- **Опрос**: анкета + скриншоты, репрезентирующие шаги анализа данных.

## 6. Оформление работы (Приложение 18)

### 6.1. Технические требования

- Редактор: Microsoft Word 7.0+ или аналогичный.
- Гарнитура: **Times New Roman**.
- Кегль: **14**.
- Межстрочный интервал: **1,5**.
- Поля: верхнее 2 см; нижнее 2,5 см; левое 3 см; правое 1,5 см.
- Отступ абзаца: **1,25 см**.
- Выравнивание по ширине.
- Сноски: Times New Roman 10 кегль, выравнивание по ширине, отступ 1,25 см.

### 6.2. Стандарты оформления

- **ГОСТ Р 7.0.100-2018** — для списка литературы.
- **ГОСТ Р 7.0.5-2008 + ГОСТ Р 7.0.108-2022** — для оформления ссылок.
- **APA стиль** — если работа выполнена на английском языке.

Не допускается параллельное использование различных вариантов оформления. Рекомендованное: система постраничных сносок со сквозной нумерацией + библиографический список в конце.

### 6.3. Прочее

- **Первой страницей** является **Введение** (на нём проставляется номер страницы).
- Каждая новая глава начинается с новой страницы (это же относится к Введению, Заключению, Списку источников, Приложениям).
- Таблицы, рисунки, графики, формулы — **выносятся в приложение** работы (не в основной текст). Нумерация сквозная во всём Приложении.
- Список источников — алфавитный порядок. Сначала русскоязычные, затем иностранные.

## 7. Шкала оценивания (по критериям, с весами)

> Для справки GPT (в UI студенту это не показывается — но это важно для оценки качества работы и точных рекомендаций).

### 7.1. Веса критериев для ИКР

| № | Критерий | Вес |
|---|----------|-----|
| 1 | **Введение** выполняет ознакомительную функцию и на основе релевантных академических источников даёт читателю представление о причинах выбора темы, её исследовательской ценности, цели и структуре работы | **0.05** |
| 2 | **Концептуальная глава** — релевантность источников, анализ научной дискуссии, корректность авторских обобщений, ясность причинно-следственной связи, обоснованность концептуализации | **0.25** |
| 3 | **Методы сбора данных и инструментария** — обоснование, корректность, использование результатов концептуальной части при разработке инструментов | **0.25** |
| 4 | **Метод анализа эмпирических данных** — корректность анализа, интерпретация результатов | **0.25** |
| 5 | **Заключение** — демонстрация полученного нового знания, соотнесение с академической дискуссией, направления дальнейшего исследования | **0.20** |
| | **Итого** | **1.00** |

### 7.2. Веса критериев для КП

| № | Критерий | Вес |
|---|----------|-----|
| 1 | **Введение** — ознакомительная функция, состояние рынка, цели/задачи бренда, ситуация на рынке и целевая аудитория в соответствии с брифом заказчика; основные концепции; структура | **0.05** |
| 2 | **Концептуальная глава (раздел «Анализ научной литературы»)** — релевантность источников, анализ дискуссии, корректность обобщений, причинно-следственные связи, концептуализация | **0.20** |
| 3 | **Концептуальная глава (раздел «Анализ рынка»)** — информированность о состоянии рынка и поведении потребителя; анализ бренда/конкурентов/бенчмарков; релевантность выбранных брендов; выводы; угрозы/возможности/потребности | **0.20** |
| 4 | **Методы сбора данных** — обоснование, корректность, использование концептуальной части | **0.20** |
| 5 | **Анализ эмпирических данных** — корректность, интерпретация | **0.20** |
| 6 | **Заключение** — демонстрация знания для решения задачи заказчика; соотнесение с дискуссией и анализом рынка; структура будущей практической части | **0.15** |
| | **Итого** | **1.00** |

### 7.3. Шкала баллов (для каждого критерия)

| Балл | Описание |
|------|----------|
| **10** | Студент может тренировать старших и линейных специалистов в области. |
| **9** | Студент может обучать младших специалистов. |
| **8** | Отличные знания и навыки; не требуется дополнительное обучение для младшей должности специалиста. |
| **6–7** | Хорошие знания, для младшей должности нужно доп. обучение. |
| **4–5** | Базовые знания, есть пробелы. |
| **0–3** | Мало знаний или их нет; не обладает навыками. |

При выставлении 9–10 баллов руководитель обязан привести дополнительную аргументацию с конкретными примерами.

## 8. Использование сервиса «Чекер курсовых» (роль и ограничения)

- Сервис анализирует структуру и содержание работы относительно требований выше и даёт **рекомендации по улучшению**.
- Сервис **не выполняет работу за студента** — он указывает на структурные пробелы, дисбаланс объёмов, несоответствие требованиям, проблемы стиля/логики.
- Сервис **не заменяет научного руководителя**: окончательное решение по работе принимает он.
- Сервис **не проверяет оригинальность** (это компетенция системы «Антиплагиат» в ЭИОС).
- Сервис **не присваивает оценку**: критерии оценивания и веса используются только для того, чтобы рекомендации были привязаны к реальным требованиям.
